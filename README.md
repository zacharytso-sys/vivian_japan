# 東京五日輕鬆遊 · 旅行手冊 + 雲端記帳系統

> 一套為東京自由行打造的**手機優先**行程手冊，整合了**可即時共編的雲端記帳**與**自動化花費分析**。
> 行程頁、記帳頁、分析頁三者互通，用 GitHub Pages 免費架站，手機加到主畫面即為 App。

行程範例：2026/7/29–8/2，2 位大人，住宿新宿。你可以直接改成自己的行程。

---

## 這個專案有什麼

| 頁面 | 檔案 | 功能 |
|------|------|------|
| 🗓️ **行程手冊** | `index.html` | 五天逐時段行程、每站一鍵開 Google Maps 導航、成田特快取票攻略（含手繪動線圖）、備案清單、出發前待辦 |
| 💰 **記帳本** | `ledger.html` | 多幣別即時記帳，自動抓匯率換算台幣，一筆一筆寫入 Google 試算表 |
| 💸 **花費分析** | `Ledger-analyze.html` | 讀取試算表，自動算出總支出、分類佔比圓餅圖、每日花費、預算進度 |

三頁透過頂部導覽列互相跳轉，構成一套完整的「行前規劃 → 旅途記帳 → 花費檢視」流程。

---

## 特色

- **手機優先設計**：版面為手機螢幕最佳化，用 Safari 開啟後可「加入主畫面」變成全螢幕 App。
- **一鍵導航**：行程每一站都有「開啟導航」按鈕，直接跳 Google Maps。
- **離線也能看**：行程頁為純靜態 HTML，搭配匯出的 PDF，沒網路時行程、訂位號碼、取票資訊照樣看得到。
- **多幣別記帳**：支援日圓、台幣、美金等，串接即時匯率 API 自動換算。
- **雲端共編**：記帳資料存在 Google 試算表，兩人以上可同時記帳、即時同步。
- **自動分析**：分析頁即時讀取試算表，產生圓餅圖與預算進度，不需手動計算。
- **無框架、零相依**：純 HTML / CSS / 原生 JavaScript，不需 build、不需安裝任何套件。

## 系統架構

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   index.html    │────▶│   ledger.html   │────▶│Ledger-analyze   │
│   行程手冊       │◀────│   記帳本         │◀────│   .html 分析     │
└─────────────────┘     └────────┬────────┘     └────────┬────────┘
     純靜態                       │ 寫入                   │ 讀取
                                  ▼                        ▼
                        ┌──────────────────┐    ┌──────────────────┐
                        │ Google Apps      │───▶│  Google 試算表    │
                        │ Script (寫入端點) │    │  (資料儲存)       │
                        └──────────────────┘    └──────────────────┘
                                                  即時匯率 API
                                             (open.er-api.com)
```

- **行程頁**不需任何後端，放上去就能用。
- **記帳頁**透過 Google Apps Script 部署的 Web App 端點，把每筆資料寫進 Google 試算表。
- **分析頁**用 Google 試算表的 GViz CSV 介面直接讀取資料。

## 快速開始（架設你自己的版本）

### 步驟 1：建立 GitHub repository 並上傳

1. 建立一個新的 repository（設為 **Public**）。
2. 上傳這三個檔案：`index.html`、`ledger.html`、`Ledger-analyze.html`。
3. 若只想用行程頁，單獨上傳 `index.html` 即可。

### 步驟 2：開啟 GitHub Pages

1. 進入 repo 的 **Settings → Pages**。
2. **Source** 選 `Deploy from a branch`，**Branch** 選 `main`、資料夾 `/ (root)`，按 **Save**。
3. 等 1–2 分鐘，網址生效：`https://你的帳號.github.io/repo名稱`
4. 用 Safari 開網址 → 分享 → **加入主畫面**，即成 App 圖示。

到這裡，**行程頁就能用了**。記帳與分析需要再做下面的設定。

### 步驟 3：設定記帳後端（Google 試算表 + Apps Script）

記帳與分析功能需要你自己的 Google 試算表當資料庫：

1. **建立一份 Google 試算表**，第一列標題依序為：
   `日期時間 / 項目 / 外幣幣別 / 外幣金額 / 匯率 / 台幣金額 / 支付方式 / 類別 / 海外手續費 / 總支出含手續費`
2. **建立寫入端點**：在試算表 → 擴充功能 → Apps Script，貼上一段接收 POST 並 `appendRow` 的程式，部署為「網頁應用程式」（存取權：任何人），取得 `.../exec` 結尾的網址。
3. **填入設定**：
   - 打開 `ledger.html`，把 `GAS_URL` 換成你上一步取得的網址。
   - 打開 `Ledger-analyze.html`，把 `SHEET_ID` 換成你的試算表 ID（網址中 `/d/` 和 `/edit` 之間那串）。
4. **開放分析頁讀取**：分析頁要讀試算表，需將試算表設為「知道連結的任何人可檢視」，或用「檔案 → 共用 → 發布到網路」發布成 CSV（分析頁內附設定說明）。

## 自訂成你自己的行程

打開 `index.html`，行程資料就是純 HTML，照現有格式改即可：

- **改天數/日期**：每個 `<section class="day dN" id="dN">` 是一天，`.dayhd` 是當天標題。
- **改景點**：每個 `<li class="stop">` 是一個行程點，含時間、名稱、說明、導航連結。
- **改導航連結**：`<a class="map" href="...">` 裡的 Google Maps 網址換成你的目的地。
- **改分析頁的旅程參數**：打開 `Ledger-analyze.html`，修改 `PEOPLE`（人數）、`TRIP_START`、`TRIP_DAYS`、`DAY_LABEL`（每日標籤）。

## ⚠️ 公開前務必注意（安全性）

GitHub Public repository 的內容**所有人都看得到原始碼**。上傳前請確認：

1. **Google Apps Script 網址（`GAS_URL`）會被公開。**
   任何人拿到這個網址都能對你的試算表寫入資料。若擔心被灌垃圾，可在 Apps Script 端加上簡單的密鑰驗證，或改用私人的 repository。
2. **試算表 ID（`SHEET_ID`）會被公開。**
   請確認試算表**只開放「檢視」而非「編輯」**，且裡面不要放個人隱私資料。
3. **行程頁裡的個人資訊**：範例行程含飯店訂單號、車票取票碼等。若你填入自己的真實資料，記得這些也會隨公開網頁被看到——敏感號碼建議只留在自己的 PDF 備份，不要放進公開頁面。
4. 若你只是想私下和同行者共享、不想公開，可將 repo 設為 **Private**，或改用 [Netlify Drop](https://app.netlify.com/drop) 之類的服務。

## 技術細節

- **前端**：純 HTML5 + CSS3 + 原生 JavaScript，無任何框架或建置工具。
- **字型**：系統內建 CJK 字型；手繪圖使用 SIL OFL 授權的 Yomogi、Zen Maru Gothic。
- **匯率**：[open.er-api.com](https://open.er-api.com)（免費，無需金鑰）；抓取失敗時自動退回內建預設匯率。
- **資料儲存**：Google 試算表（透過 Apps Script 寫入、GViz CSV 讀取）。
- **手繪圖**：行程頁的成田機場動線圖、售票機操作圖等，皆為手工繪製的 SVG，非外部圖片，無版權疑慮。
